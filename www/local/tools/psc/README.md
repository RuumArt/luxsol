# Справочник почтовых индексов Slovenská pošta

Сюда кладутся файлы, которые пошта публикует на
https://www.posta.sk (раздел «PSČ – súbory na stiahnutie»):

- `OBCE.xlsx` — населённые пункты (обязателен)
- `ULICE.xlsx` — улицы городов с несколькими индексами (обязателен)
- `POBoxy.xlsx` — индексы абонентских ящиков (необязателен)

`ULICE.xlsx` именно обязателен: в `OBCE.xlsx` у 163 крупнейших городов
колонка PSČ пустая, вместо индекса стоит пометка «Pozri zoz.ulíc s PSČ».
Индексы Братиславы, Кошиц, Банской Бистрицы, Жилины есть только там.

Пошта обновляет списки примерно раз в месяц. Обновление справочника:

    php local/tools/import_psc.php            # разбор без записи, проверка
    php local/tools/import_psc.php --apply    # загрузка в базу

Старые файлы можно просто перезаписать новыми.
