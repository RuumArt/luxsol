Почтовый шаблон напоминания об оплате авансовой фактуры

Тип события: LUXSOL_ADVANCE_INVOICE_REMINDER
Основа: действующее клиентское HTML-письмо SALE_NEW_ORDER для сайта s1.
Используются его SITE_TEMPLATE_ID, EMAIL_FROM и LANGUAGE_ID.
Тело: advance-invoice-reminder.sk.html. Адрес для ответа: office@luxsol.sk.

Установка при общей выкладке ветки

После переноса файлов выполнить из корня сайта под пользователем PHP:
php -d short_open_tag=1 local/tools/mail_advance_invoice_reminder.php
php -d short_open_tag=1 local/tools/mail_advance_invoice_reminder.php --apply

Первая команда показывает план, вторая создаёт тип события и шаблон в БД
Битрикс. Если подходящих исходных шаблонов несколько, указать --source=ID.
ID исходного шаблона определяется на окружении, а не зафиксирован в коде.
Повторный запуск не создаёт дублей и не перезаписывает изменения из админки.
Текущий workflow переносит файлы; этот установщик сам из workflow не запускается.

Редактирование после установки

Настройки > Настройки продукта > Почтовые события > Почтовые шаблоны.
Отфильтровать по типу LUXSOL_ADVANCE_INVOICE_REMINDER.
Текст можно менять в админке. Файл HTML задаёт первоначальное содержимое.

Поля для будущего вызова почтового события

EMAIL — e-mail клиента.
ORDER_NUMBER — номер заказа.
INVOICE_NUMBER — номер zálohovej faktúry.
AMOUNT_WITH_CURRENCY — сумма с валютой, например 23,80 €.
DUE_DATE — срок оплаты, например 23. 10. 2026.
IBAN — счёт для оплаты.
VARIABLE_SYMBOL — переменный символ.

В теле письма используются #HTML_...# — Битрикс сам экранирует исходные
значения. Вызывающий код должен передавать обычный текст, а не готовый HTML.
Получатель, сумма и реквизиты не зашиты в шаблон.

Установка не отправляет писем и не добавляет событий в очередь. Проверка
неоплаченных заказов, заполнение полей, команда ручной отправки и расписание
автоматических напоминаний в эту задачу не входят и не включены.
Почтовая тема получает название Luxsol s.r.o. и не выводит MID в теле письма
через обработчики room/eventHandlers/mail.php.
